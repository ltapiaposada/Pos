# Planes y soporte

## Propuesta de planes

### Plan Base POS
- Punto de venta
- Inventario
- Compras
- Caja
- Reportes
- 1 empresa
- 1 sucursal inicial

### Plan Comercio Plus
- Todo lo del Plan Base POS
- Contabilidad base
- Cartera
- Multiples usuarios
- Ecommerce de pedidos web con validacion manual

### Plan Restaurante
- Todo lo del Plan Comercio Plus
- Menu web
- Pedidos delivery/takeaway
- Cocina
- Flujo restaurante

## Implementacion
Cada venta debe aclarar si incluye:
- instalacion
- configuracion inicial
- creacion de administrador inicial
- carga de datos
- capacitacion
- soporte post salida a produccion

## Soporte sugerido

### Soporte inicial
- Correccion de errores de salida
- Ajustes menores de configuracion
- Acompanamiento de arranque

### No incluido por defecto
- Desarrollo a medida
- Integraciones nuevas
- Pasarela de pago
- Facturacion electronica por pais
- Infraestructura de hosting

## Acuerdos minimos recomendados
- Horario de soporte
- Canal de soporte
- Tiempo de respuesta objetivo
- Alcance de cambios incluidos
- Politica de backups
