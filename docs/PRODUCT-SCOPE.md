# Alcance comercial del producto

## Modulos base
- Punto de venta
- Inventario
- Compras
- Caja
- Reportes
- Contabilidad base
- Multiempresa
- Ecommerce
- Restaurante

## Alcance vendible hoy

### POS
- Ventas mostrador
- Apertura y cierre de caja
- Control de inventario
- Clientes y proveedores
- Compras
- Reportes operativos

### Contabilidad
- Registro contable de ventas
- Registro contable de compras
- Cartera basica
- Pagos y recaudos

### Ecommerce
- Catalogo web
- Carrito
- Pedido web
- Seguimiento basico
- Pago manual por transferencia o QR
- Contraentrega

### Restaurante
- Catalogo/menu web
- Pedidos delivery o para llevar
- Flujo hacia cocina
- Cierre posterior en operacion/caja

## Lo que no debe prometerse todavia
- Pasarela de pago automatica
- Conciliacion bancaria automatica
- Webhooks de pagos
- Facturacion electronica garantizada para un pais especifico
- SLA empresarial formal sin contrato de soporte

## Definicion comercial del ecommerce
El ecommerce actual debe venderse como:
- `pedido web con validacion manual`
- `catalogo online con carrito`
- `checkout con transferencia, QR o contraentrega`

No debe venderse como:
- `checkout con tarjeta integrado`
- `pago online automatico`
- `pasarela de pago incluida`
